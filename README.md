Global Superstore Power BI Dashboard
Project Overview
This project analyzes Global Superstore sales data from 2011 to 2014 using Microsoft Power BI.
Business Objective
To help management monitor sales, profitability, customer segments, product performance, and regional performance.
Dataset
Global Superstore: 51,290 records and 24 original columns.
Tools Used
•	Microsoft Power BI
•	Power Query
•	DAX
•	Microsoft Excel
Dashboard Features
•	Five KPI cards
•	Eight visualizations
•	Interactive slicers
•	Executive insights and recommendations
Key Findings
•	Total Sales: $12.64M
•	Total Profit: $1.47M
•	Total Orders: 25,035
•	Profit Margin: 11.61%
•	Technology is the highest-performing product category by sales and profit.
Business Recommendations
Improve Furniture profitability, expand profitable Technology sales, investigate regional performance differences, and strengthen customer retention.
